# Security Policy

## Reporting A Vulnerability

Please do not open public issues for suspected vulnerabilities.

Report security issues privately by emailing security@clovord.com with:
- A clear description of the issue
- Reproduction steps or proof of concept
- Affected versions and environment details
- Any suggested mitigation

If email is not possible, use GitHub Security Advisories for private disclosure.

## Response Expectations

- Initial acknowledgment: within 72 hours
- Triage status update: within 7 calendar days
- Remediation timeline: shared after triage based on severity and impact

## Supported Versions

Security fixes are provided for the following release lines:
- Latest stable release (`0.x` current)
- Previous stable release line when still actively maintained

If your version is outside supported lines, update to a supported release before requesting a fix.

## Disclosure Process

After a fix is available, Clovord may publish:
- A changelog note
- A GitHub Security Advisory (when applicable)

We ask reporters to avoid public disclosure until a fix is released or a coordinated date is agreed.
